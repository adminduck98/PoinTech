## 1. Общая информация

|----------|----------|

## 7. Edge Functions (10 шт.)

| Функция | Назначение | Ключевые возможности |
|---------|-----------|---------------------|
| `client-api` | Пользовательский API gateway | Rate limiting (30 req/min/IP), Telegram initData HMAC-SHA256, upsert_user, favorites CRUD, reviews, notifications, returns, coupons |
| `admin-api` | Админский CRUD gateway | SHA-256 token, 18 таблиц, select/insert/update/delete, уведомления при смене статуса заказа |
| `admin-login` | Авторизация | bcrypt, rate limit (5 попыток/15 мин), session token |
| `checkout` | Оформление заказа | Валидация stock, защита от подмены цен, купоны, RPC `create_order_with_stock` |
| `create-payment` | Платежный шлюз | Payme (checkout URL), Click (redirect), Uzum Bank (API) |
| `payme-callback` | Payme webhook | JSON-RPC: CheckPerformTransaction, CreateTransaction, PerformTransaction, CancelTransaction |
| `send-message` | Telegram отправка | Direct message + product notification, rate limit 30 msg/sec |
| `auto-notify` | Автоуведомления | Триггеры БД: price drop → notify_price, stock change → notify_stock |
| `process-broadcast` | Рассылка | Очередь broadcast_jobs, rate limit 25 msg/sec, progress updates |
| `setup-storage` | Storage setup | Создание bucket `product-images` (public, 10MB, png/jpeg/webp) |
| `_shared/telegram-verify` | Проверка Telegram | Pure JS HMAC-SHA256 для initData |

## 8. Telegram Bot

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация + главное меню |
| `/start product_SLUG` | Deep link: показать товар |
| `/menu` | Главное меню |
| `/help` | Справка |
| `/orders` | Мои заказы (с фото товаров) |
| `/favorites` | Избранные товары (с фото) |
| `/support` | Связаться с поддержкой (режим пересылки сообщений админу) |
| `/faq` | Часто задаваемые вопросы |
| `/about` | О магазине |
| `/broadcast` | Массовая рассылка (только ADMIN_ID) |
| `/stats` | Статистика (только ADMIN_ID) |

**Возможности бота:**
- Кнопка "Открыть магазин" (Telegram WebApp)
- Отображение заказов с фотографиями товаров
- Избранное с уведомлениями (скидки, наличие)
- Режим поддержки: пересылка сообщений пользователей администратору
- Массовая рассылка: direct (<100 пользователей) / queued (≥100 через broadcast_jobs)
- Rate limiting 25 msg/sec, обработка Forbidden/BadRequest/RetryAfter
