## Найденные и исправленные проблемы

### 1. Поиск товаров — 404 (ИСПРАВЛЕНО ✅)

**Проблема:** PostgREST фильтр `.or()` с JSONB `->` оператором возвращал 404 для всех запросов поиска.

**Решение:** Заменить на прямой PostgREST фильтр `name->>ru=ilike.*...*` (text extraction вместо JSONB extraction).

**Файл:** `loadtest/test.js` — сценарий `scenarioSearch`

### 2. Checkout Edge Function — 404 (ОБНАРУЖЕНО, ТРЕБУЕТ ДЕПЛОЯ)

**Проблема:** Edge Function `checkout` не задеплоена на Supabase (404 для всех запросов).

**Решение:** Требуется деплой:
```bash
supabase functions deploy checkout --project-ref wrjixyedostqulufnjpw
```

### 3. client-api — 401 (ОБНАРУЖЕНО, ТРЕБУЕТ Telegram init_data)

**Проблема:** Edge Function `client-api` требует валидного Telegram init_data для user-scoped действий.

**Решение:** Нормальное поведение — в продакшене клиент отправляет init_data от Telegram WebApp.
